# vaudio

Car stereo head unit, implemented with an ESP32 Wroom.

Rock solid, 60 Hz UI and no nonsense.

Has worked flawlessly for over a year (so far).

Overview
- Double DIN front plate with electronics on back side
- Bluetooth audio receiver
- OLED display (128x64 monochrome)
- Volume knob on rotational encoder (dB scale)
- Chunky buttons (mute, connect, menu, up, down, select, cancel)
- 2x USB-A ports (one charge 1.5A, one UART 500mA).
- Relay output for amp remote
